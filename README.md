# Computational Mathematics — Warm-Up Repo

Welcome to your first repository. This repo is where you'll practice the git
workflow you'll use all year: **pull → edit → commit → push**.

## Your first task (from the GitHub Account Setup worksheet)

1. Open `hello.py`
2. Change the print line to say your name and one math fact about you
3. Save, then commit and push (exact commands are on your worksheet)
4. Refresh this page on github.com and look for your change

## The git cycle (memorize this)

```
git add <file>       # stage your change
git commit -m "..."  # describe your change
git push             # send it to GitHub
```

Every assignment in this course follows the same cycle. Bigger repos, same three commands.
